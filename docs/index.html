Evolving the Prototype Journey: Lifelong Vision-and-Language Navigation with Prototype Adaptation

Gan Li, Xudong Wang, Yue Liao, Xuewei Lv, Jiahua Dong, Xiyao Liu, Yanbo Wang, Pinle Qin, Lianqing Liu, Senior Member, IEEE, and Zhi Han, Member, IEEE

Abstract

Adapting vision-and-language navigation (VLN) agents to continually evolving environments is crucial for robust deployment in dynamic real-world scenarios. However, naively fine-tuning agents on newly encountered scenes often causes catastrophic forgetting of previously learned environments and degrades their generalization ability to unseen scenes. In this paper, we propose EverWalker, a lifelong VLN agent that continuously evolves its navigation knowledge through a prototype-driven adaptation mechanism. Rather than storing independent scene-specific adapters to mitigate forgetting, EverWalker maintains a Dynamic Prototype Bank (DyproBank), which incrementally accumulates compact observation prototypes to encode essential navigation knowledge. Built upon this evolving prototype space, we further introduce a Prototype-conditioned Hypernetwork (PHYP-Net), which dynamically generates step-level adaptive LoRA parameters conditioned on aggregated prototypes. This design enables efficient step-specific inference without relying on explicit task identifiers. In addition, we develop a multi-level distillation strategy to facilitate progressive knowledge accumulation across continual scenes while preserving previously acquired navigation capabilities. Extensive simulation and real-world experiments demonstrate the effectiveness of EverWalker in mitigating catastrophic forgetting and improving generalization under lifelong VLN settings.

Method

Illustration for the proposed EverWalker. EverWalker consists of two core components: A Dynamic Prototype Bank maintains an evolving library of scene prototypes with soft routing for knowledge aggregation. A Prototype Hypernetwork dynamically generates task-specific LoRA conditioned on aggregated prototypes, enabling adaptive navigation while preserving shared knowledge.

Real-World Experiments Setting

Illustration of the proposed robotic navigation system. The platform integrates a quadruped robot for mobility, a camera for visual perception, and a remote server for running the EverWalker agent, enabling closed-loop real-world navigation. To validate the effectiveness of EverWalker in real-world scenarios, we construct a physical robotic navigation platform as illustrated in Figure. The hardware configuration consists of a quadruped robot (DeepRobotDog Lite2) serving as the mobile agent, a high-definition RGB camera (Hikvision DS-E12) mounted for egocentric perception, a high-bandwidth portable WiFi communication module, and a remote computation server equipped with 8 NVIDIA RTX A6000 GPUs.
